# Contribuindo com o Lay-OS

1. Leia `docs/ARCHITECTURE.md` e `docs/ROADMAP.md`.
2. Abra uma issue descrevendo a mudanca antes de PRs grandes.
3. Commits no formato `tipo: descricao` (`feat`, `fix`, `docs`, `chore`, `refactor`).
4. Scripts shell devem passar em `shellcheck`.
5. Toda decisao de arquitetura relevante vai em `docs/` (ADR curto).
